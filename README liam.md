* ###### **Exécution :**







* ###### **Installation :**

&nbsp;	-  Vous utiliserez une interface en ligne de commande (CLI), selon votre système :

&nbsp;		Windows : PowerShell (ou Git Bash, recommandé)

&nbsp;		macOS : Terminal

&nbsp;		GNU/Linux : Terminal

&nbsp;	**Installer Git :**

&nbsp;		- Windows : tapez dans PowerShell : 

&nbsp;			*winget install --id Git.Git -e --source winget*



&nbsp;		- Git Bash est recommandé, car sa syntaxe est identique à Linux/macOS.

&nbsp;			- Linux (sur Ubuntu) : *sudo apt install git*

&nbsp;			- MacOs : déjà installé ou via Homebrew : *brew install git*

&nbsp;		- Vérifier l'installation :

&nbsp;			tapez : *git --version*

&nbsp;		    	Vérifier que vous avez bien la bonne version en fonction de vos 				préférences.

&nbsp;	**Configurer Git :**

&nbsp;		Les modification apportésdans Git sont associées à votre nom et à votre adresse 		email. Il est donc nécessaire de les configurer sur votre ordinateur, avec :

&nbsp;		*git config --global user.name "Votre Nom"*

&nbsp;		*git config --global user.email votre.email@example.com*

&nbsp;		

&nbsp;		Vous pouvez vérifier vos paramètre avec : 

&nbsp;			*git config --list*	ou	*git config <paramètre>*



&nbsp;	**Installer GitHub CLI:**

&nbsp;		Installer GitHub CLI depuis ce lien : https://cli.github.com/

&nbsp;	**Configurer GitHub CLI :**

&nbsp;		Entrée : *gh auth login*

&nbsp;		puis sélectionné : "GitHub.com" ; "SSH" ; "Skip" ; "Login with a web Browser" ;

&nbsp;		et suivez les instructions.

&nbsp;	

&nbsp;	**Installer AlgoBox :**

&nbsp;		Installer AlgoBox depuis ce lien : https://www.xm1math.net/algobox/
